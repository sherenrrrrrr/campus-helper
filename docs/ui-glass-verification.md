# 问问磨砂玻璃精修验收

首次验收基于当时 `main` 的 `ebf38a0`。本轮保留系统宋体，欢迎区水彩不透明度设为 0.30。合并来源核对和积分界面简化后，钱包只展示可用积分与发布入口。

## 样式结构

- 原有两个主题 `:root` 块分别为 8、47 行，另有 34 条亮色覆盖规则，共 52 行选择器和声明。现在默认与暗色令牌块分别为 51、30 行，亮色覆盖规则为零。独立的问卷图形资源块仍为 10 行。
- 背景模糊使用两组共享声明，覆盖顶部导航、底部导航、钱包、入口面板、弹窗和账号菜单六处。问卷卡片和看板统计采用中性表面渐变与顶部内高光。
- 等宽数字从正文和表单控件继承，覆盖钱包、问卷积分与名额、进度、时间、流水金额和看板统计。
- 检查了降低透明度、降低动画和不支持背景模糊的样式分支。三种回退未在相应的系统设置或浏览器中独立实测。

## 对比度

运行 `node scripts/check-glass-contrast.cjs`。透明表面先叠加主题底色，渐变取两个端点的较低对比度。按附件要求，将原本只有 4.41∶1 的浅色次要文字调深至 `#536C7F`。

| 前景与背景 | 亮色 | 暗色 | 下限 |
| --- | ---: | ---: | ---: |
| 正文与卡片 | 7.48 | 9.43 | 4.5 |
| 次要文字与页面底色 | 4.91 | 6.76 | 4.5 |
| 次要文字与导航 | 5.23 | 5.51 | 4.5 |
| 标题与卡片 | 12.09 | 12.71 | 7 |
| 白字与主按钮 | 6.99 | 6.99 | 4.5 |
