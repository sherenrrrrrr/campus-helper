# 校园问卷互助平台产品待办

记录日期：2026 年 11 月 17 日。

以下仅记录想法与待办，尚未实施。不修改当前网页，也不替换产品方案 v2 中已经确定的业务规则。

## 匿名发布问卷

- [ ] 发布问卷时允许同学选择是否匿名。
- [ ] 在发布前预览匿名后的展示效果，让发布者知道其他同学会看到什么。
- [ ] 待确定：匿名是否默认关闭，以及大厅、详情和审核记录分别如何显示发布者身份。
- [ ] 设计时确认匿名只影响公开展示，不影响任务归属、积分结算、申诉和管理员追溯。

## 在介绍区上传截图或文件

- [ ] 在“介绍一下你的问卷”区域增加截图或文件上传入口。
- [ ] 已有问卷介绍材料时，可以直接提供材料，减少重复手填标题、说明和主题的步骤。
- [ ] 保留原来的手动填写方式，让没有现成材料的同学也能发布。
- [ ] 待确定：支持的文件类型、大小、张数，以及材料是直接作为介绍展示，还是用于提取并预填字段。
- [ ] 若采用自动提取，允许发布者检查、修改结果；不能把无法识别的信息伪装成已经识别成功。

这里的材料是发布者提供的“问卷介绍材料”，与答题者填写后上传的“完成页证明”是两个不同入口，不能混用。

## 保留预计耗时

- [ ] 暂按“预计耗时仍保留”记录，方便答题者判断是否参与。
- [ ] 可考虑从材料中带出耗时，或提供可修改的默认值，减少填写负担。
- [ ] 待确认：语音中的“号史”是否指“耗时”。如果不是，应先更正这条记录，再开发。

## 链接及其他信息预填

- [ ] 考虑为链接等字段提供预填能力，减少发布步骤。
- [ ] 能从材料中明确提取的信息，可考虑自动带出；没有依据的信息留给发布者确认，不随意生成真实问卷链接。
- [ ] 待确定：“预填”是指演示版自带示例值，还是从上传材料中自动识别，或两者都需要。
- [ ] 预填后仍允许修改，并继续执行已有的链接格式校验和重复问卷检查。

## 此前反馈待排查

- [ ] 管理员后台没有看到描述中的内容：继续确认入口是否明显、切换管理员后的落点，以及申诉队列、任务管理、用户管理、数据看板的展示是否符合预期。

## 开发前确认

当前只完成需求记录。待确认耗时、材料呈现方式及预填来源后，再安排页面设计和开发；不因本待办自动启动实现。
